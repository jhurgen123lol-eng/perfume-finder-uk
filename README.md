# Perfume Finder UK

This is the initial front-end prototype for the Perfume Finder UK project.

## Important
The current version is a visual/interactive prototype only. Its scan is simulated and its sample business records are fictional. It does not perform live discovery or collect real contact details yet.

Next development steps:
1. Connect a permitted business discovery/search API through a secure backend.
2. Store results in a database and deduplicate businesses.
3. Add secure configuration for API credentials (never place secrets in browser code or this repository).
4. Deploy the web app and test live scans.
5. Consider a browser extension after the web app is working.
